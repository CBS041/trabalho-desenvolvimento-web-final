# 🎣 Pega na Vara

Aplicação web desenvolvida como projeto final da disciplina de Desenvolvimento Web, com foco na construção de uma interface completa para uma plataforma voltada à pesca esportiva.

O projeto apresenta informações sobre pesca, espécies de peixes, guias especializados e locais para pescaria, além de páginas de contato e autenticação.

## ✨ Funcionalidades

* Página inicial com apresentação do projeto
* Área sobre a plataforma
* Catálogo de espécies de peixes
* Guia de informações sobre peixes
* Relatório de guias de pesca
* Relatório de locais de pesca
* Página de contato
* Tela de login
* Navegação entre múltiplas páginas
* Layout responsivo
* Menu de navegação adaptado para dispositivos móveis
* Organização de assets de imagens, estilos e scripts

## 🎨 Interface

O projeto utiliza uma identidade visual baseada em tons naturais, com destaque para elementos relacionados à pesca esportiva.

A interface foi construída considerando:

* Hierarquia visual
* Componentização estrutural através de classes CSS
* Responsividade
* Acessibilidade básica
* Navegação entre páginas
* Adaptação para dispositivos móveis

## 🚀 Execução local

Por ser uma aplicação estática, não é necessário instalar dependências ou configurar um servidor backend.

Clone o repositório:

```bash
git clone https://github.com/CBS041/trabalho-desenvolvimento-web-final.git
```

Entre no diretório:

```bash
cd trabalho-desenvolvimento-web-final
```

Depois, abra `pages/index.html` no navegador.

Também é possível utilizar uma extensão como **Live Server** para executar o projeto durante o desenvolvimento.
